# Hunter's Fang necklace three-quarter v4

Generated with the built-in image-generation workflow using the frontal
Hunter's Fang as the identity reference and the current three-quarter hunter as
the perspective and fit reference.

The final geometry is an open front U with no rear or top chain. Screen-left is
the far side: its collar-to-pendant chain run is approximately two-thirds the
projected length of the screen-right near side, using fewer, smaller, compressed
links. The near side uses larger, more separated links on a longer, deeper
drape. Both open endpoints terminate at approximately the same collar height so
they disappear beside the neck rather than landing on the shoulder.

The generated chroma source uses a flat `#FF00FF` background. The runtime alpha
asset was produced with `remove_chroma_key.py` using border auto-detection,
soft matte, despill, transparent threshold 12, and opaque threshold 220.
