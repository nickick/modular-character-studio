## Shared prompt

Create a production-ready four-piece boot equipment sprite sheet for the
Goblin Hunter three-quarter modular character rig. Use the first reference only
for layout, scale, rendering style, and component separation. Use the second
reference as the authoritative design, materials, colors, motifs, and
silhouette. Use a wide landscape canvas with exactly four isolated pieces from
left to right: one tall lower-leg shaft viewed three-quarter front-left, one
redundant alternate tall shaft candidate, one separate left foot shell viewed
three-quarter front-left, and one separate right foot shell viewed
three-quarter front-right. Both shaft pieces must be leg-only gaiters from below
the knee to the ankle, ending in a narrow open ankle cuff, with no toe, foot,
sole, or heel. The foot shells must contain the complete toe, vamp, outsole, and
heel, with a short upward ankle tongue. Pieces must not overlap or touch. The
game uses the leftmost shaft and the first foot shell twice, mirroring each for
the right leg, so pieces one and three must be clean, complete, centered, and
suitable for mirroring. The alternate shaft and final foot remain provenance
candidates only. Use thick
near-black ink outlines, angular faceted shapes, hand-painted mobile fantasy RPG
sprite rendering, warm upper-left light, and no cast shadows. Use a uniform
solid chroma-magenta background, #ff00ff, with hard edges and no gradient or
texture. Include no character, legs, text, labels, weapons, or extra objects.

During runtime import, Starcaller, Emberward, and Forest Stalker's right-foot
PNG is a byte-for-byte copy of the left foot with no horizontal mirroring.
